# Instrucciones del proyecto para asistentes de IA

- Proyecto: juego de memoria individual con Next.js App Router, React y TypeScript.
- Trabajar exclusivamente dentro de la raíz del proyecto.
- Nunca abrir, leer, imprimir, copiar o modificar archivos `.env*`, claves privadas, tokens o credenciales.
- Nunca intentar acceder a rutas externas a este proyecto.
- No ejecutar `git push`, despliegues, instalaciones ni comandos con efectos externos sin permiso explícito del estudiante.
- No inventar evidencias, pruebas ejecutadas, commits, métricas ni URLs de producción.
- Mantener el reductor puro, inmutable y separado de React.
- Usar botones semánticos, foco visible, anuncios `aria-live` y etiquetas en español.
- No introducir servicios externos, Firebase ni bases de datos.
- Verificar cambios con `npm run check` cuando estén instaladas las dependencias.
- Las pruebas usan Vitest y React Testing Library; cobertura mínima 80 % para `src/lib`.
- Toda intervención de IA se documenta con propósito, validación y decisión en `ia/BITACORA.md`.
- El estudiante debe revisar y comprender cada cambio antes de incorporarlo.
